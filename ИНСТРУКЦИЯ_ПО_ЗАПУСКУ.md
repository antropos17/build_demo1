## 📋 Шаг 1: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

Это установит все необходимые пакеты (Next.js, React, TypeScript, Tailwind CSS, MongoDB, и т.д.)

**Время установки:** ~2-5 минут

---

## 📋 Шаг 2: Настройка переменных окружения

Создайте файл `.env.local` в корне проекта (рядом с `package.json`):

```env
# MongoDB (можно использовать MongoDB Atlas или локальный MongoDB)
MONGODB_URI=mongodb://localhost:27017/findbuild

# NextAuth (для аутентификации - можно сгенерировать случайный ключ)
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=ваш-секретный-ключ-здесь
```

### Как получить NEXTAUTH_SECRET:

**Windows (PowerShell):**
```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

**Или просто используйте любой длинный случайный ключ**

### MongoDB:

**Вариант 1: MongoDB Atlas (облачный, бесплатный)**
1. Зарегистрируйтесь на [mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas)
2. Создайте бесплатный кластер
3. Получите connection string
4. Вставьте в `MONGODB_URI`

**Вариант 2: Локальный MongoDB**
1. Установите MongoDB на компьютер
2. Запустите MongoDB сервис
3. Используйте: `mongodb://localhost:27017/findbuild`

**Примечание:** Для первого запуска MongoDB не обязателен - проект будет работать с placeholder данными!

## ⚠️ Возможные проблемы:

### 1. Ошибки при `npm install`
- Убедитесь, что Node.js версии 18+ установлен
- Попробуйте удалить `node_modules` и `package-lock.json`, затем снова `npm install`

### 2. Порт 3000 занят
- Измените порт: `npm run dev -- -p 3001`
- Или остановите процесс, использующий порт 3000

### 3. Ошибки TypeScript
- После `npm install` ошибки должны исчезнуть
- Если остались - перезапустите VS Code / редактор

### 4. MongoDB ошибки
- Проект работает БЕЗ MongoDB с placeholder данными
- MongoDB нужен только для реальной работы с базой данных
